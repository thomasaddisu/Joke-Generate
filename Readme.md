# 😂 Random Joke Generator

A simple web application that fetches random jokes from an API and displays them on the screen.

## Demo
[demo](https://joke-generate-ecru.vercel.app/)

## 🚀 Features

- Fetches random jokes from JokeAPI
- Displays a new joke on button click
- Simple and responsive UI
- Uses modern JavaScript (Fetch API & async/await)

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- JokeAPI (https://v2.jokeapi.dev/)

## 📦 How It Works

1. User clicks the **Get Joke** button  
2. JavaScript sends a request to the API  
3. The API returns a random single-line joke  
4. The joke is displayed dynamically on the page  

## ▶️ How to Run

1. Clone or download the repository  
2. Open `index.html` in your browser  
3. Click the button and enjoy 😄  

## 📌 API Endpoint Used
  - https://v2.jokeapi.dev/joke/Any?type=single
